# Electronics

This section documents the circuit boards we currently build for the FRAME and the Discovery boxes: what each one does, its pinout, which firmware runs on it and where the design files are. It is written for people who want to repair, extend or re-use the electronics.

Two ideas explain most of the design:

- **One firmware.** Every board with a microcontroller runs [uc2-esp32](https://github.com/youseetoo/uc2-esp32), built with a different pin map. A board understands the same JSON commands whether you talk to it over USB or reach it through the bus.
- **One cable.** In a FRAME, a four-wire cable carries 12 V and CAN from board to board. Each function (a motor, the lasers, the illumination) sits on its own small board with its own controller, close to the thing it drives.

<ElectronicsOverview />

The Raspberry Pi runs ImSwitch and talks serial JSON to the ESP32 on the HAT+. The HAT+ is the CANopen master: it knows which satellite owns which motor or laser and forwards each command there. The Pi can also reach the bus directly through its own CAN controller on the HAT+. Protocol, commands and Python clients are documented in [Serial & CANopen interface](../../sw/interface/index.md).

## What every board page contains

- a rendering and a top view with the silkscreen, to find connectors
- connector and controller pinouts, taken from the PCB files of the stated revision
- solder jumpers
- the firmware environment, a link to its pin map and a command to test the board

## Flashing

All boards are flashed from the browser at [youseetoo.github.io](https://youseetoo.github.io/). The procedure, the board names used there and what to do when it fails: [Flashing the firmware](./flashing.md).

## The bus in one table

| Item | Value |
|---|---|
| Connector | JST XH 4: **1 GND, 2 +12 V, 3 CAN_H, 4 CAN_L** |
| Protocol | CANopen, 500 kbit/s, master = node 1 |
| Termination | 120 Ω at the two physical ends only. Every board has a solder jumper for it, open by default. |
| USB serial | 921600 baud on the HAT+, 115200 on the standalone board, USB-CDC (any baud rate) on XIAO boards |

Background and wiring rules: [CAN bus and power](./frame/README.md). Node IDs and routing: [Boards, roles & node IDs](../../sw/interface/reference/boards-and-node-ids.md).

- **Firmware:** [youseetoo/uc2-esp32](https://github.com/youseetoo/uc2-esp32), release binaries in [uc2-esp32-binaries](https://github.com/youseetoo/uc2-esp32-binaries).
- **Buy assembled boards:** [shop.openuc2.com](https://shop.openuc2.com). If a board is not listed, ask.
- **Questions, bug reports, your own boards:** [openuc2.discourse.group](https://openuc2.discourse.group).
