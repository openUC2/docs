# Baseplates – Referenz

> **Diataxis:** Reference
> **Gilt für:** Alle Discovery-Boxen.

---

## Zwei Baseplate-Typen

| | Puzzle-Baseplate | Solid-Baseplate |
|---|---|---|
| **Material** | ABS / PLA | POM (10 mm stark) |
| **Raster** | 1 Cube = 1 Einheit; Platten stecken zusammen | Definierte Lochfelder, beliebige Konfiguration |
| **Cube-Befestigung** | Einrasten (Clip) | M3-Schrauben von unten |
| **Vorteil** | Schnell umbauen, kein Werkzeug | Vibrationsstabil, für präzise Setups |
| **Nachteil** | Weniger stabil bei Erschütterungen | Langsamerer Umbau |
| **Typischer Einsatz** | CoreBox, Schüler-Experimente | LightSheet, ODMR, Interferometrie |

---

## Puzzle-Baseplate (Standard)

- Maße pro Einheit: **50 × 50 mm** (= ein Cube-Footprint).
- Verbindung: Stifte und Buchsen an allen vier Seiten.
- Im Set: typisch 10 Stück → max. 2×5 oder 3×4 Cubes (mit Überhang).
- Empfohlene Konfiguration: gerade Linie (Teleskop) oder L-Form (Mikroskop).

```
┌──┬──┬──┬──┬──┐
│  │  │  │  │  │   ← 1×5 Baseplate (fünf Puzzle-Platten in einer Linie)
└──┴──┴──┴──┴──┘
```

---

## Solid-Baseplate

- Standard-Größen: **4×5 Cubes** (200×250 mm) und **2×3 Cubes** (100×150 mm).
- Material: POM (Polyoxymethylen), 10 mm, schwarz.
- Gewinde: M3 im 50-mm-Raster, durchgehend gebohrt.
- Für LightSheet: mitgelieferte 4×5 POM-Platte.
- Für QBox: mitgelieferte 4×5 POM-Platte.

---

## Kompatibilität

Alle Cubes aller Discovery-Boxen passen auf beide Baseplate-Typen. Ein Mix (teilweise Puzzle, teilweise Solid) ist mechanisch möglich, aber nicht empfohlen (unterschiedliche Höhen).
